📱 项目背景

在移动应用中集成 Google Play 订阅和一次性购买（积分购买）功能，实现完整的支付体系。

🎯 核心区别：订阅 vs 积分

特性 订阅 积分（一次性购买）
支付类型 周期性自动扣款 一次性购买
是否需要ACK ✅ 必须确认 ❌ 不需要确认
是否需要消耗 ❌ 不需要 ✅ 必须消耗
退款机制 整个订阅期可退款 较短退款窗口
状态管理 复杂（激活、续订、取消） 简单（购买即完成）
API接口 subscriptionsv2.get() products.get()
确认方式 acknowledge() consume()
再次购买 自动续订 需要先消耗才能再买

🏗️ 系统架构设计

1. 数据库设计

sql

-- 用户订单表
CREATE TABLE user_orders (
    order_id VARCHAR(64) PRIMARY KEY,
    user_id BIGINT NOT NULL,
    google_purchase_token VARCHAR(512),  -- Google购买令牌
    google_order_id VARCHAR(128),        -- Google订单ID
    product_type TINYINT,                -- 1=订阅, 2=积分
    product_id VARCHAR(128),             -- 产品ID
    payment_status TINYINT DEFAULT 1,    -- 1=待支付,2=成功,3=续订,4=过期,5=退款
    consumption_state TINYINT DEFAULT 0, -- 0=未消耗,1=已消耗（仅积分）
    expiry_time DATETIME,                -- 过期时间（订阅用）
    created_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_purchase_token (google_purchase_token(64)),
    INDEX idx_status (payment_status)
);

2. 支付状态机

text

订阅状态流程：
PENDING → PAID → RENEWED → EXPIRED/CANCELLED

积分状态流程：
PENDING → PAID → CONSUMED → COMPLETED

private void handleSubscriptionPurchase(LocalOrdersParam param, LocalOrdersEntity order) {
    // 1. 获取订阅信息
    SubscriptionPurchaseV2 subscription = googlePaymentService
        .getSubscriptionGoogleOrderV2(param.getGooglePurchaseToken());

    // 2. 验证订阅状态
    if (!"SUBSCRIPTION_STATE_ACTIVE".equals(subscription.getSubscriptionState())) {
        throw new BusinessException("订阅未激活");
    }

    // 3. ACK确认（必须）
    acknowledgeSubscription(param, subscription);

    // 4. 更新订单和发放权益
    updateSubscriptionOrder(order, subscription);
    grantSubscriptionBenefits(order);
}

积分购买验证

java

private void handlePointsPurchase(LocalOrdersParam param, LocalOrdersEntity order) {
    // 1. 获取购买信息
    ProductPurchase productPurchase = googlePaymentService
        .getOneTimeGoogleOrder(order.getGoogleProductId(), param.getGooglePurchaseToken());

    // 2. 验证购买状态（0=已购买）
    if (productPurchase.getPurchaseState() != 0) {
        throw new BusinessException("购买未完成");
    }

    // 3. 检查是否已消耗
    if (productPurchase.getConsumptionState() == 1) {
        throw new BusinessException("商品已消耗，请勿重复发货");
    }

    // 4. 消耗购买（必须）
    googlePaymentService.consumePurchase(
        order.getGoogleProductId(), 
        param.getGooglePurchaseToken()
    );

    // 5. 发放积分
    grantPointsToUser(order, productPurchase);
}

步骤3：消息队列处理

java

@Component
public class GooglePurchaseMessageListener {

    @RabbitListener(queues = "google.purchase.queue")
    public void handlePurchaseMessage(String message) {
        LocalOrdersParam param = parseMessage(message);
        LocalOrdersEntity order = getOrder(param.getOrderId());

        // 使用分布式锁防止重复处理
        String lockKey = "purchase:" + param.getOrderId();
        RLock lock = redissonClient.getLock(lockKey);

        try {
            if (lock.tryLock(5, TimeUnit.SECONDS)) {
                if (order.getProductType() == 1) {
                    processSubscription(param, order);
                } else if (order.getProductType() == 2) {
                    processPoints(param, order);
                }
            }
        } finally {
            lock.unlock();
        }
    }
}

@Scheduled(cron = "0 0 2 * * ?")  // 每天凌晨2点
public void checkSubscriptionStatus() {
    // 获取所有活跃订阅
    List<LocalOrdersEntity> activeSubscriptions = getActiveSubscriptions();

    for (LocalOrdersEntity order : activeSubscriptions) {
        try {
            SubscriptionPurchaseV2 subscription = googlePaymentService
                .getSubscriptionGoogleOrderV2(order.getGooglePurchaseToken());

            // 更新本地状态
            updateLocalStatus(order, subscription);

        } catch (PurchaseTokenExpiredException e) {
            // 订阅已过期

        }
    }
}

🎯 核心要点总结

  1. 订阅必须ACK，积分必须消耗 - 这是 Google Play 的政策要求
  2. 处理好410错误 - 令牌过期是正常现象，要有优雅处理
  3. 防止重复处理 - 使用分布式锁和状态检查
  4. 区分首次和续订 - 续订的支付状态要单独标记
  5. 完善的错误处理 - 宁可返回空也不返回错误格式
  6. 定期状态同步 - 保持本地与 Google 状态一致
